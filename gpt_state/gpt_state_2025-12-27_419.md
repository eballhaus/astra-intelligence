# 🧠 Astra Intelligence — GPT_STATE
_Last updated: 2025-12-27_

---

## 🧩 PROJECT OVERVIEW

Astra Intelligence is a **multi-agent market intelligence engine** with:
- **Agents** (`/agents/personas/`): Momentum, Technical, Volume, Risk, Psychology, Catalyst, Neural.
- **Engine** (`/engine/`): RankingEngine, DataOrchestrator.
- **Guardian** (`/guardian/`): Data firewall and fallback system.
- **UI/Dashboard** (`/ui/astra-dashboard/`): React front-end pulling live data from the FastAPI backend.
- **API** (`/api/live_server.py`): Lightweight FastAPI service serving `/api/live-data`.

Main function:  
> Serve live Astra AI forecasts (stocks + crypto) with buy/sell grades, confidence, and summary insight.

---

## ⚙️ CURRENT ENVIRONMENT

**Backend:**  
- Runs via `uvicorn api.live_server:app --host 0.0.0.0 --port 8000 --reload`  
- Live endpoint: `http://127.0.0.1:8000/api/live-data`  
- Uses `engine/data_orchestrator.py` as the orchestrator.  
- GuardianV7 active in fallback mode (Yahoo data when direct feed unavailable).

**Frontend:**  
- Located in `/ui/astra-dashboard/`
- Uses React + Vite.
- Displays two columns (stocks left, crypto middle) and a right-hand TradingView chart.
