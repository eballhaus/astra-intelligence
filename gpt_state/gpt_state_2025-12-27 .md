🎨 DASHBOARD OBJECTIVE — “ASTRAGLASS” DESIGN SPEC
🔹 Overall Look
Bright, crisp, glass-like aesthetic — “AstraGlass” theme:
Semi-transparent panels with soft glow and shadow.
High contrast text (white / light blue).
Rounded card edges and smooth hover elevation.
Light blue gradient background for visual depth.
Layout mirrors a professional trading terminal.
🔹 Layout Requirements
Header (top area)
Title only — remove subtitle lines such as
“Autonomous Prediction & Learning System” or “Live System Snapshot”.
Centered Astra logo and name: 🧠 Astra Intelligence
Market Overview Row
Horizontal bar with:
S&P 500, NASDAQ, DOW, Bitcoin
Each item shows ▲▼ arrows + % change.
Classes: .market-strip, .market-title, .market-item, .up, .down
Main Grid
Two-column structure:

    +--------------------------------------------------------+
|  STOCK CARDS (6)        |  ADVANCED CHART PANEL        |
|  CRYPTO CARDS (6)       |                              |
+--------------------------------------------------------+


Left: “Stocks” and “Crypto” card columns (.cards-area)
Right: Interactive TradingView-style chart (.chart-area)
🔹 Card Requirements
Each Astra Card must display:
Symbol (ex: AAPL)
Live price (from backend)
Astra prediction: $ and %
Stop-loss: $ and %
Astra confidence %
Astra grade (A+, A, B, etc.)
One short reasoning line (“Why Astra chose it”)
Interaction: Clicking any card updates the right-side chart symbol immediately.
🔹 Chart Requirements
If full TradingView Charting Library unavailable, fallback to:
lightweight-charts with:
Candles + Volume
MA / EMA
RSI / MACD / Bollinger / ATR / Stoch / Supertrend
Indicator toggle buttons for on/off control
