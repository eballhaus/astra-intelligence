## 🧠 SYSTEM OVERVIEW

**Astra Intelligence** is a multi-agent analytics platform for stocks, crypto, and market fundamentals — powered by dynamic modules (“Agents”), live API integration (“Guardian”), and a Streamlit-based dashboard interface.  
It provides real-time persona analysis for tickers such as AAPL, TSLA, NVDA, etc., with individual AI agents modeling risk, momentum, sentiment, catalysts, and neural patterns.

The system is composed of four main layers:
1. **Engine Layer** – data orchestration, Guardian interface, API control.  
2. **Core Layer** – GuardianV7 unified safety, logging, and API handler.  
3. **Modules Layer** – AI agents (Neural, Momentum, Technical, Volume, Risk, Psychology, Catalyst).  
4. **UI Layer** – Streamlit dashboard with persona summaries and visualization.
